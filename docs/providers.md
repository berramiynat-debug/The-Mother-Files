## Field ownership and failures

- **TVmaze** owns cast attribution, show dates, summaries, and series order. Episode details verify the embedded show ID from the direct episode request. The episode list supplies optional previous and next links. Actor details are restricted to people in the show’s canonical cast.
- **TMDB** owns optional media paths. The server accepts only GET requests for fixed show ID 1100 and small integer season/episode bounds. The browser receives filtered data and never supplies or receives the credential. Successful proxy results are cached.
- **HIMYM Character API** contributes attributed metadata. The app validates and deduplicates aliases and quote samples. It discards quotes with missing authors, missing lines, or long excerpts.
- **Original fiction** drives mysteries, dialogue, and pub activities. API failure affects only the dependent interactions. Provider-level failures and empty results have distinct UI.

## The Mosby Margins

The notebook uses a server-side `POST /api/hints` in Vite dev, Vite preview, and the Vercel Node function. Only free-plan `openai/gpt-oss-20b` is supported by this application. The published free-plan limits are 30 requests/minute, 1,000 requests/day and 8,000 tokens/minute for the model. A local live smoke test against Groq returned HTTP 200, the 1,000-request daily and 8,000-token minute limit headers, and a structured selection that the notebook mapped to a Turkish hint. [Groq model documentation](https://console.groq.com/docs/model/openai/gpt-oss-20b) · [Groq rate limits](https://console.groq.com/docs/rate-limits)

- Quick questions and step-by-step hints use local rules. A custom question sends at most 400 characters and the relevant reviewed fictional records, available actions, and checked deductions. Conversation history stays in memory for the current chapter, up to six replies. The game sends no archive preferences other than the spoiler setting.
- The server reconstructs chapter context from validated IDs. Groq selects a reply and English or Turkish through a strict schema. The available replies distinguish the next action, records to review, records to cite, reasoning help, and specific facts in opened records. The application maps the selection to approved plain text. Provider timeouts, missing credentials, and HTTP 429 use a local fallback that also considers the question.
- The function accepts same-origin browser requests and caps bodies at 4 KiB, provider calls at 4.5 seconds, and completions at 256 tokens. Each running instance allows one outstanding request per IP, three requests/minute per IP, and up to 12 requests/minute and 150/day across clients. Vercel supplies the client IP when deployed. These counters reset with the process, so the Groq project’s free-plan quotas are the account-wide limit. Vercel’s path-based WAF can provide a deployment-wide request rule for `/api/hints`.
